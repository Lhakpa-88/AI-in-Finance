# Preparation Checklist (per cohort)

## Logistics
- [ ] Cadence chosen and scheduled
- [ ] Venue / virtual rooms + breakout rooms configured
- [ ] Every participant confirmed to have AI tool access
- [ ] Shared drive for datasets and handouts set up

## Content
- [ ] Synthetic datasets built and pressure-tested (budget, transaction export, bank statement + cash book, partner ledger + vouchers, timesheet extract, donor-guideline excerpt)
- [ ] Deliberate "gotcha" failures seeded (wrong total, invented regulation, data-protection trap)
- [ ] Module 6 sampling procedure localised to main donors' expenditure-verification requirements
- [ ] Module 5 localised: donor cost-principle excerpt + local tax/VAT/TDS provision
- [ ] Every demo prompt pre-tested on the current tool versions

## Participant-facing
- [ ] Assessment rubric shared in advance
- [ ] Data Red-Line Card printed / shared
- [ ] Module briefs ready to distribute per session

## Safety
- [ ] Confirmed: no real donor / salary / beneficiary data will enter the room
- [ ] `.gitignore` respected — no data files committed to any shared repo
