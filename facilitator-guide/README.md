# Facilitator Guide

How to run *AI for Finance Professionals*. Read `../course-design/course-design.md` and `../course-design/delivery-methodology.md` first.

## Before the cohort
1. Pick a cadence (weekly recommended — see delivery methodology).
2. Prepare and pressure-test the synthetic datasets (`synthetic-data/`).
3. Localise Module 5 to the cohort's real donors and tax jurisdiction.
4. Pre-test every prompt on the day's actual tools — outputs drift as models update.
5. Confirm every participant has access to at least one general-purpose AI assistant.
6. Share the assessment rubric up front so participants know verification is graded.

## Running a session
Use the five-phase rhythm (launch → diagnose → work → verify → share) from the delivery methodology. Protect the **verify** phase above all.

## The facilitator stance
- Coach, don't rescue.
- Celebrate catching the AI in an error — that is the skill.
- Model the data red-lines; never bring real data into the room.
- Keep groups mixed by experience.
