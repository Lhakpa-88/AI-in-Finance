# Portfolio & Capstone Guide

## The portfolio (60%)
Each module produces one artifact. Collected, these form the participant's evidence of competence **and** a reusable personal toolkit:

| Module | Portfolio artifact |
|---|---|
| 0 | Personal "trust ledger" |
| 1 | Data Red-Line Card |
| 2 | Draft grant budget + reviewer critique addressed |
| 3 | Three-audience variance narrative set |
| 4 | Reusable data-cleaning recipe |
| 5 | Worked eligibility determination with clauses |
| 6 | Audit-prep checklist + management-response template |
| 7 | Two-scenario cash-flow projection + board narrative |
| 8 | Capstone package + org AI-Use Playbook draft |

## The capstone (30%)
An integrated, realistic mixed brief worked end-to-end in groups, with a data-protection trap embedded. Assessed on the full rubric, plus an **individual reflection**: what they'd use AI for at work, what they never would, and the one verification habit they're taking away.

## Verification discipline (10%)
Graded by observation across all sessions. Did the participant check the AI's work, protect data, and cite sources — without being prompted?
