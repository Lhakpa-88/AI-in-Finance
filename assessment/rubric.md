# Competency Rubric

Assessment is **evidence of applied competence**, not recall. Finance professionals learn by doing, so there is no exam.

## Weighting
| Component | Weight | What it is |
|---|---|---|
| Portfolio | 60% | The artifact produced in each module |
| Capstone | 30% | The integrated group deliverable + individual reflection |
| Verification discipline | 10% | Observed throughout: checking work, protecting data, citing sources |

## Rubric dimensions
Each deliverable is assessed across five dimensions. Score 1 (emerging) – 4 (strong).

| Dimension | 1 — Emerging | 4 — Strong |
|---|---|---|
| **Task quality** | Output incomplete or incorrect | Accurate, complete, fit for the stated audience |
| **Verification rigour** | Accepts AI output as-is | Independently checks every number/claim against source |
| **Data protection** | Would expose sensitive data | Applies red-lines and de-identification by reflex |
| **Grounding** | Relies on AI's memory | Feeds authoritative sources; traces claims to them |
| **Judgement** | Uses AI indiscriminately | Knows when *not* to use AI and says so |

## Pass standard
A participant passes when they score **3+ on verification rigour and data protection across the portfolio** — these two dimensions are non-negotiable, because they are the point of the course.
