# Module 4 — Excel & Messy-Data Wrangling
**Duration: 2.5 hours** · Part of *AI for Finance Professionals* (20-hr PBL course)

> Standalone facilitator brief. See `../course-design/delivery-methodology.md` for the session rhythm used in every module.

## Problem scenario
A bank/ledger export arrives with merged cells, inconsistent date formats, and duplicate rows. Reconciliation is tomorrow morning.

## Learning objectives
Participants can use AI to write and *explain* formulas, clean and standardise data, and build summaries from plain-language instructions — accepting no formula they can't explain.

## Concepts
- Writing and explaining formulas with AI
- Cleaning and standardising data
- Pivot summaries from natural-language instructions

## Tools
Spreadsheet-embedded AI for in-context help; general-purpose assistants to explain or debug a formula and generate cleaning steps.

## Hands-on
Each group gets the same deliberately messy dataset and races to a clean, reconciled summary — documenting every AI-assisted step so it's repeatable.

## Verification focus
Spot-check AI-written formulas on known values. Never accept a formula you can't explain back.

## Deliverable
A reusable **data-cleaning recipe** for the participant's own recurring export.
