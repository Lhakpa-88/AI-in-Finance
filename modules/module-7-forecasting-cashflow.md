# Module 7 — Forecasting, Cash Flow & Scenarios
**Duration: 2.0 hours** · Part of *AI for Finance Professionals* (20-hr PBL course)

> Standalone facilitator brief. See `../course-design/delivery-methodology.md` for the session rhythm used in every module.

## Problem scenario
The board wants a six-month cash-flow projection with a base case and a "delayed disbursement" case, by next week.

## Learning objectives
Participants can use AI to structure a projection, articulate assumptions, and write scenario narratives — while owning the drivers and figures as professional judgement.

## Concepts
- Structuring a cash-flow model with AI
- Making assumptions explicit
- Generating scenario narratives

## Hands-on
Groups build a simple two-scenario cash-flow projection and use AI to write the board-facing explanation of each scenario and its assumptions.

## Verification focus
Interrogate every assumption the AI proposes. Label assumptions explicitly so the board sees judgement, not black-box output.

## Deliverable
A two-scenario cash-flow projection + board narrative.
