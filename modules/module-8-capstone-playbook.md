# Module 8 — Capstone + Organisational AI-Use Playbook
**Duration: 3.0 hours** · Part of *AI for Finance Professionals* (20-hr PBL course)

> Standalone facilitator brief. See `../course-design/delivery-methodology.md` for the session rhythm used in every module.

## Problem scenario (integrative)
Groups receive a realistic mixed brief — a grant closeout with a budget revision, a donor report, a compliance question, and a **deliberately embedded data-protection trap**. They must deliver a complete, verified package *and* explain how they kept it safe.

## Part A (2 hrs) — Capstone
Each group works the integrated problem end-to-end, applying every discipline from the course. Presentations + peer review against the rubric (`../assessment/rubric.md`).

## Part B (1 hr) — The playbook
The cohort co-drafts a lightweight **Organisational AI-Use Playbook** to take back (template in `../resources/ai-use-playbook-template.md`):
- 1–3 approved finance use cases to start with
- The data red-lines (what never goes in)
- The human sign-off step for each use case
- Who owns and monitors it (typically the finance/operations director)
- A simple log so use is visible, not shadow

This mirrors the "narrow-and-governed" model that distinguishes high-impact adopters.

## Deliverable
Completed capstone package + a first-draft AI-Use Playbook for the participant's organisation.
